## ⭐️ Где мы сейчас (snapshot для нового чата)

**Сделано в первой сессии (вторник, 12-13 мая):**
- Архитектура утверждена: 4 источника (Habr Career + Telegram + SuperJob + Trudvsem), без парсинга hh.ru, JSON-файлы вместо БД на v1.0.
- Стек: Next.js 14 + TypeScript + Tailwind + Vercel Cron + Vitest (Vitest ещё не подключён).
- Профессии MVP: 4 текущие (Копирайтер, SMM, Таргетолог, SEO).
- Секретный ключ SuperJob перевыпущен, вынесен в `.env.local`, в коде читается из `process.env`. Старый ключ светился в публичном git-history — теперь бесполезен.
- API-роут `/api/salary` теперь читает `src/data/<profession>.json` вместо live-запроса в SuperJob. Скорость ответа ~50 мс.
- Восстановлен богатый UI (звёзды, эмодзи, попапы при наведении, кастомные дропдауны) из коммита `3f2f92e`.
- Починен баг с дропдаунами (теперь кликаются — ref-based outside-click вместо blind document listener).
- Написан `METHODOLOGY.md` — полная методология сбора и обработки данных. Канонический документ для любых работ с цифрами.

**Что сейчас работает на сайте:**
- Копирайтер с богатым UI: 1787 вакансий по России, ~800 Москва, ~300 СПб.
- Остальные 3 профессии: «Скоро добавим» (нет JSON-файлов).

**Открытые вопросы / гипотезы:**
- 🔥 **Дина предположила:** SuperJob и Habr вместе могут давать в разы меньше вакансий, чем hh.ru. Если так — придётся либо подключать парсинг hh.ru (отвергнутое решение пересмотреть), либо очень агрессивно качать Telegram и Trudvsem. Проверять в задаче #19.
- Anthropic API key для Telegram-extractor пока нет — Дина заведёт, когда дойдём до задачи #14.
